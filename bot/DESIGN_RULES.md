# Правила формирования КП WorkHere

## ФИЛОСОФИЯ ДИЗАЙНА

**Думай как Артемий Лебедев:**
- Каждый элемент должен быть на своём месте
- Пустота — это проблема, которую нужно решить
- Баланс визуала и контента
- Никакого визуального мусора
- Чистая типографика

---

## 0. Технические ограничения WeasyPrint

- `display: flex/grid` — НЕ РАБОТАЮТ, использовать таблицы
- Google Fonts — НЕ РАБОТАЮТ, использовать Arial
- Эмодзи — НЕ РАБОТАЮТ, использовать текст
- Сложные псевдоэлементы — упрощать

---

## 1. Структура документа

6 разделов + 4 маскота:

1. Что обсуждали на встрече
   → МАСКОТ 1
2. Решение WorkHere
   → МАСКОТ 2
3. Стоимость
4. Внедрение
   → МАСКОТ 3
5. Почему WorkHere
6. Следующие шаги
   → МАСКОТ 4 (финальный, самый большой)

---

## 2. Правила маскотов (КРИТИЧНО!)

### Принцип:
**Маскоты ЗАПОЛНЯЮТ пустое пространство.**
Чем меньше контента — тем БОЛЬШЕ маскоты.

### Размеры:
- Базовый размер: **180px** (большой по умолчанию!)
- Уменьшать ТОЛЬКО если много контента
- Минимум: **120px**
- Финальный маскот: **+40px** к базовому

### Алгоритм:
```
base = 180px

if features >= 7: base -= 40
elif features >= 5: base -= 20

if situation > 200 chars: base -= 20
elif situation > 100 chars: base -= 10

if both_tariffs: base -= 10
if ai_module: base -= 10

base = max(base, 120)

size_1 = base
size_2 = base + 10
size_3 = base + 20
size_4 = base + 40  # Финальный
```

### 4 позиции маскотов:
1. После раздела 1 — заполняет пустоту после списка
2. После раздела 2 — заполняет пустоту после функционала
3. После раздела 4 — заполняет пустоту после внедрения
4. Перед футером — финальный, самый большой

---

## 3. Правила отображения цен

### Блок "Итого":
- Отдельный блок по центру
- Шрифт **16pt** (не огромный, но заметный)
- Компактный padding

### Формат:
```
┌─────────────────────┐
│    Итого в год      │  <- 10pt
│    80 000 ₽         │  <- 16pt bold
└─────────────────────┘
```

### Расчёт для команды:
- Каждый тариф на **отдельной строке**
- НЕ в одну строку через пробел

---

## 4. Нумерация

### Разделы:
- Синий кружок с цифрой 1-6
- Размер кружка: 24px

### Шаги внедрения:
- **БЕЗ кружков!** Просто цифры 01, 02, 03, 04
- Синий цвет, крупный шрифт

---

## 5. Типографика

- Основной шрифт: **11pt**
- Межстрочный: **1.6**
- Заголовки разделов: **13pt bold**
- Подзаголовки: **10.5pt bold**, синий цвет

---

## 6. Отступы

- Между разделами: **25px**
- После маскотов: **20px**
- Внутри блоков: **12-15px**

---

## 7. Цветовая схема

- Основной акцент: **#597FFF**
- Успех/результаты: **#10B981**
- Фон блоков: **#F0F4FF**, **#F8FAFC**
- Текст: **#1a1a2e**, **#666**

---

## 8. Чек-лист перед генерацией

- [ ] 4 маскота на своих позициях
- [ ] Размеры маскотов рассчитаны по алгоритму
- [ ] Нет пустых страниц
- [ ] Блок "Итого" компактный
- [ ] Шаги без кружков (01, 02, 03, 04)
- [ ] Каждый тариф на отдельной строке

---

## 9. Целевые метрики

- Страниц: **3-4**
- Маскотов: **4**
- Разделов: **6**
- Размер файла: **100-200 KB**
