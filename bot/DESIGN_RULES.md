# Правила формирования КП WorkHere

## 1. Структура документа

Каждое КП должно содержать следующие разделы:

1. **Шапка** — логотип WorkHere + данные клиента (компания, контакт)
2. **Заголовок** — "Коммерческое предложение" + подзаголовок
3. **Что обсуждали** — персонализированный блок из транскрибации
4. **Решение WorkHere** — функционал системы (релевантный клиенту)
5. **Стоимость** — таблица цен + расчёт для конкретной команды
6. **Внедрение** — шаги запуска
7. **Почему WorkHere** — преимущества + результаты клиентов
8. **Следующие шаги** — CTA
9. **Контакты** — футер

## 2. Визуальные правила

### Размеры и отступы
- Шрифт основной: 10-11pt
- Заголовки разделов: 12-13pt
- Межстрочный интервал: 1.5
- Отступы между разделами: 16-20px

### Цветовая схема
- Основной акцент: #597FFF (синий WorkHere)
- Успех/результаты: #10B981 (зелёный)
- Фон блоков: #F0F4FF (светло-синий), #F8FAFC (серый)
- Текст: #1a1a2e (тёмный), #666 (серый)

### Типографика
- Заголовки: жирные (700-800)
- Подзаголовки: полужирные (600)
- Акценты: синий цвет или жирный

## 3. Правила заполнения пустот

### Когда вставлять маскота:
- После раздела "Что обсуждали" — ВСЕГДА
- Между разделом "Решение" и "Стоимость" — если есть место
- После раздела "Почему WorkHere" — ВСЕГДА
- В конце документа перед футером — ВСЕГДА

### Размер маскота:
- Маленький (60-80px): inline рядом с текстом
- Средний (100-120px): между разделами
- Большой (150-200px): заполнение больших пустот

### Фразы для маскота:
Ротация из списка:
- "Разберёмся с рутиной — будет время на важное!"
- "Все отклики в одном месте — красота!"
- "Автоматизация — это про нас!"
- "Меньше рутины, больше результата!"
- "Будем рады видеть вас в WorkHere!"
- "Ваша команда скажет спасибо!"

## 4. Правила контента

### Раздел "Что обсуждали":
- Минимум 6 пунктов
- Каждый пункт — развёрнутое предложение
- Включать детали из разговора (имена систем, количества, специфику)

### Раздел "Решение":
- Показывать только релевантные модули
- AI-модуль показывать только если выбран Премиум или AI-опция
- Группировать по подразделам (2.1, 2.2, etc.)

### Раздел "Стоимость":
- Таблица с позициями
- Блок расчёта для конкретной команды (N рекрутеров)
- Итоговая сумма выделена крупно

## 5. Адаптивность

### Количество страниц:
- Оптимум: 3-4 страницы
- Минимум: 2 страницы
- Максимум: 5 страниц

### Если документ короткий (< 3 стр):
- Увеличить маскотов
- Добавить больше деталей в "Решение"
- Развернуть "Внедрение"

### Если документ длинный (> 4 стр):
- Сократить списки
- Убрать дублирующие пункты
- Уменьшить маскотов

## 6. Дизайн-элементы

### Обязательные:
- Нумерованные разделы в синих кружках
- Highlight-боксы для важной информации
- Таблица цен с чередованием фона
- Двухколоночный блок "Для рекрутеров / Для руководителей"
- Зелёный блок результатов

### Рекомендуемые:
- Иконки/эмодзи для визуального разнообразия (умеренно)
- Разделительные линии между секциями
- Карточки для шагов внедрения

## 7. Файлы маскотов

Расположение: `/bot/assets/mascots/`

Именование: `mascot_01.svg`, `mascot_02.svg`, etc.

При генерации PDF выбирается случайный маскот для каждой позиции.
