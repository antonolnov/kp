# Правила генерации КП WorkHere

## Процесс генерации

```
1. GPT-4o анализирует транскрибацию → JSON с контентом (1 запрос)
2. Cursor генерирует PDF из шаблона
3. Cursor проверяет КАЖДУЮ страницу по критериям
4. Cursor проверяет ВЕСЬ файл по критериям
5. Если есть проблемы → исправление и перегенерация
```

---

## Критерии проверки КАЖДОЙ СТРАНИЦЫ

| # | Критерий | Описание |
|---|----------|----------|
| 1 | **Заполненность** | Не более 20% пустого пространства внизу страницы |
| 2 | **Целостность** | Разделы НЕ разрываются между страницами |
| 3 | **Заголовки** | Заголовок всегда вместе с контентом (не внизу страницы один) |
| 4 | **Маскот** | Присутствует, не перекрывает текст, размер адекватный |
| 5 | **Маркировка списков** | Стрелки/галочки НЕ наезжают на текст, НЕ дублируются внутри пункта |
| 6 | **Визуальный баланс** | Нет "каши" — элементы не слипаются, есть воздух между блоками |
| 7 | **Читаемость** | Текст не мелкий, контраст достаточный |

---

## Критерии ФИНАЛЬНОЙ проверки всего файла

| # | Критерий | Описание |
|---|----------|----------|
| 1 | **Персонализация** | Название компании упоминается минимум 3 раза |
| 2 | **Связность** | Боли → Решения → Выгоды логически связаны |
| 3 | **Конкретика** | Нет шаблонных фраз ("оптимизация", "эффективность" без контекста) |
| 4 | **Цены** | Расчёт корректный под количество рекрутеров |
| 5 | **Структура** | Все 6 разделов присутствуют |
| 6 | **Объём** | 3-4 страницы, не больше |
| 7 | **Единообразие** | Стиль оформления одинаковый на всех страницах |

## Визуальные правила

### Отступы и "воздух"
- Между разделами: 18px
- Между подразделами: 10px
- Между пунктами списка: 4px
- Padding в боксах: 10-12px

### Маркировка списков
- Стрелка `→` для обычных списков
- Галочка `✓` для выгод (зелёная)
- Маркер отделён от текста: 16px padding-left
- НИКОГДА не дублировать маркеры

### Размеры текста
- Заголовок документа: 18pt
- Заголовки разделов: 12pt
- Подзаголовки: 10pt
- Основной текст: 10pt
- Мелкий текст (шаги): 8-9pt

### Маскоты
- Размер: 80-130px (компактные)
- Позиция: после разделов 1, 2, 4 и в конце
- Фраза в облачке: max 180px ширина

### Цвета
- Основной синий: #597FFF
- Зелёный (галочки): #10B981
- Фон боксов: #F0F4FF (светло-синий)
- Текст: #1a1a2e

- [ ] Нет разрывов разделов
- [ ] Нет пустых страниц
- [ ] Маскоты отображаются
- [ ] Цены рассчитаны правильно
