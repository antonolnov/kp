# WorkHere КП Bot

Telegram-бот для генерации персонализированных коммерческих предложений на основе транскрибации встреч.

## Возможности

- 📝 Прием транскрибации встречи (текст, .txt, .docx)
- 🤖 AI-анализ с помощью Claude (извлечение болей, потребностей, обсуждаемых функций)
- 📊 Выбор тарифа (Стандартный / Премиум / Оба)
- 🔍 Опциональный ИИ-поиск кандидатов для стандартного тарифа
- 📄 Генерация персонализированного PDF (4 страницы)
- 📋 История КП с автоочисткой (хранится 3 дня)

## Тарифы

| Тариф | Цена | AI |
|-------|------|-----|
| Стандартный | 20 000 ₽/лицензия/год | Опционально |
| Премиум | 42 000 ₽/лицензия/год | Включён |
| ИИ-поиск | 5 000 ₽/мес или 50 000 ₽/год | — |

## Установка

### 1. Системные зависимости (для WeasyPrint)

```bash
# Ubuntu/Debian
sudo apt-get install libpango-1.0-0 libpangocairo-1.0-0 libgdk-pixbuf2.0-0 libffi-dev shared-mime-info

# macOS
brew install pango gdk-pixbuf libffi
```

### 2. Python зависимости

```bash
cd bot
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

Содержимое `.env`:
```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
CURSOR_API_KEY=ваш_ключ_cursor
```

## Запуск

```bash
cd bot
python3 main.py
```

## Использование

1. Отправьте `/start` боту
2. Отправьте транскрибацию встречи (текст или файл)
3. Выберите тариф
4. Получите готовый PDF

### Команды

- `/start` — начать работу
- `/new` — создать новое КП
- `/history` — история сгенерированных КП
- `/help` — справка
- `/cancel` — отменить текущую операцию

## Структура проекта

```

├── requirements.txt     # Зависимости

```

## Что извлекается из транскрибации

- Название компании
- Имя контактного лица
- Количество рекрутеров
- Текущие боли в процессе найма
- Потребности клиента
- Обсуждаемые функции WorkHere
- Конкретный запрос (если есть)
- Ситуация в найме

## Структура КП (4 страницы)

1. **Обложка** — персонализированное приветствие, ключевые метрики
2. **Анализ ситуации** — боли, потребности, заинтересовавшие функции
3. **Возможности** — обзор платформы с акцентом на обсуждаемые функции
4. **Стоимость** — тарифы и расчёт для команды клиента
